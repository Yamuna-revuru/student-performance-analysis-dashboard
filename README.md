
# Student Performance Analysis Dashboard

## Overview
An interactive data analytics dashboard built with Python and Streamlit to explore student academic performance, study habits, previous failures, and attendance patterns.

## Features
- Interactive school, gender, study-time, and final-grade filters
- Key performance indicators and pass-rate analysis
- Final-grade distribution visualization
- Study-time and past-failure analysis
- Absence-level analysis
- Correlation heatmap
- Student data search and exploration
- Download filtered records as CSV
- Dynamic findings and recommendations

## Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit

## Run Locally
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Create and activate a Python virtual environment.
4. Install the dependencies:

   `python -m pip install -r requirements.txt`

5. Start the dashboard:

   `python -m streamlit run dashboard.py`

6. Open the local URL shown in the terminal.

## Project Purpose
This project demonstrates data cleaning and filtering, exploratory data analysis, data visualization, KPI reporting, and interactive dashboard development.
